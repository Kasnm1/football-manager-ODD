## 더 깊게 운영하고, 더 오래 기억하는 커리어

FMODD는 Football Manager 커리어를 위한 Windows 로컬 데스크톱 도구입니다. 소유한 클럽을 운영하고 선수 훈련과 팀 활동을 계획하며, 경기 외에도 자금과 인력을 관리할 수 있습니다. 선수의 성장 과정, 기억에 남는 경기와 인물 관계도 기록합니다.

기능은 현재 세이브와 게임 날짜를 기준으로 작동합니다. 경기 콘텐츠에는 ODD 가상 자금이 사용됩니다. 일부 클럽, 인물 및 훈련 기능은 버전 검증을 통과한 뒤 FM의 실제 데이터를 변경합니다. 사용 가능한 기능은 정확한 게임 빌드와 배포 플랫폼에 따라 달라집니다.

## V2.7.0beta · 선수의 다음 구단 찾기

**활동 센터 2F → 선수 이적**에서는 다른 활동과 마찬가지로 오른쪽 사이드바에서 선수를 선택합니다. 「새 구단 찾기」를 누르면 구매 구단의 제안을 카드로 보여 주는 창이 열립니다.

- 산하 클럽의 사용 가능한 선수를 대상으로 하며, 요청할 때 최대 다섯 구매 구단의 제안을 생성합니다.
- 선수의 명성과 나이를 참고하며, 이미 인수했거나 현재 감독을 맡고 있는 클럽은 구매 후보에서 제외합니다.
- **ODD 평가액**은 현재 세이브의 활용 가능한 선수 표본을 참고합니다. 카드에는 클럽, 대회와 제안 금액이 표시됩니다.
- 수락 전 이적 내용을 확인합니다. 이적료는 **판매 구단의 이적 예산**에 반영됩니다.

이 제안은 FMODD가 플레이 콘텐츠로 무작위 생성하는 가상 제안이며, FM 게임의 구단이 실제로 보낸 이적 제안과 구분됩니다.

## 시작하기

1. **[공식 다운로드 페이지](https://fmodd.com/download)**에서 Windows 버전을 받으세요.
2. Football Manager를 실행하고 사용할 세이브를 불러오세요.
3. FMODD를 실행해 해당 게임 버전을 선택한 뒤 현재 세이브에 연결하세요.
4. 클럽, 훈련, 활동과 경기 콘텐츠를 살펴보세요.

게임 데이터를 변경하는 기능을 처음 사용하기 전에 세이브를 백업해 주세요. Beta 버전의 호환성과 기능은 계속 조정됩니다.

| 환경 | 현재 범위 |
| --- | --- |
| 운영체제 | Windows 데스크톱 프로그램 |
| 게임 세대 | FM24 / FM26, 각 버전의 데이터 구조와 기능을 검사 |
| 배포 플랫폼 | Steam / Epic / XGP, 정확한 빌드를 기준으로 검증하며 지원 범위가 다를 수 있음 |
| 인터페이스 | 다국어, 표시 환경 설정 및 글자 크기 설정 |
| 현재 버전 | **V2.7.0beta** |
